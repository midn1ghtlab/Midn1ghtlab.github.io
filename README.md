# Old Layout for YouTube™

**Old Layout for YouTube™** is a lightweight browser extension that restores the classic YouTube watch layout by safely disabling the latest UI experiments.

## ✨ Features
- **Restores Classic Design:** Disables the new grid layout, side-rail panels, and split-scroll experiments.
- **Fast & Lightweight:** Hooks directly into native YouTube events (`yt-navigate-finish`) to ensure the layout stays intact as you browse, without requiring full page reloads.
- **Privacy First:** We do not collect, store, or transmit any of your personal data or browsing history. Everything runs 100% locally.

## 🚀 Installation
You can install the official extension directly from your browser's store:

- **Google Chrome:** [Install from Chrome Web Store](https://chromewebstore.google.com/detail/bpbhnliecejnhjkmeidbipmgpjegoamm)
- **Mozilla Firefox:** [Install from Firefox Add-ons](https://addons.mozilla.org/en-US/firefox/addon/old-layout-for-youtube/)
